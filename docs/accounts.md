# 账号管理

工具支持添加多个百度网盘账号，所有凭证仅保存在本机 `data/data.json` 中，不会上传到任何第三方服务器。

## 方式一：浏览器自动登录（推荐）

1. 打开「账号管理」→ 点击「添加账号」
2. 点击「🌐 浏览器自动登录」
3. 工具会用 puppeteer-core 调起你本机的 Chrome/Edge，打开百度登录页
4. 在弹出的浏览器中完成登录（扫码 / 账号密码 / 短信验证均可）
5. 登录成功后工具自动读取 Cookie 并保存账号，无需手动复制

> 登录用的浏览器 profile 保存在 `data/login-profile/`，下次登录可复用会话。

## 方式二：手动粘贴 Cookie

1. 浏览器登录 [百度网盘网页版](https://pan.baidu.com)
2. 按 `F12` 打开开发者工具 → `Network`（网络）标签
3. 刷新页面，点击任意一个发往 `pan.baidu.com` 的请求
4. 复制请求头中的完整 `Cookie`
5. 粘贴到「添加账号」弹窗的 Cookie 输入框

**Cookie 必须包含以下字段**（缺一不可）：

| 字段 | 作用 |
|---|---|
| `BDUSS` | 核心登录凭证 |
| `STOKEN` | 网盘会话令牌 |
| `BAIDUID` | 设备标识（生成 logid 用） |
| `ndus` | 网盘用户会话 |

## 代理设置

添加账号时可填写代理，支持：

- `http://127.0.0.1:7890`
- `https://127.0.0.1:7890`
- `socks://127.0.0.1:7890` / `socks5://...`

每个账号独立配置，该账号的所有 API 请求都走对应代理。

## 账号失效处理

Cookie 一般数周内有效。如果出现：

- 获取文件列表失败 `errno=-6`（身份验证失败）
- 页面提示"未能获取 bdstoken"

说明 Cookie 已过期，删除旧账号重新添加即可。

## 安全提示

- `data/data.json` 包含完整登录凭证，**不要分享、不要提交到 git**（仓库已默认 .gitignore）
- 删除账号会同时删除该账号的检测记录、任务历史和重复文件扫描快照
