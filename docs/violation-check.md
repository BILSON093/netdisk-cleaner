# 和谐文件检测

检测网盘中被百度和谐的文件，支持批量扫描整个目录树。

## 检测原理

基于百度网盘网页版的下载直链探测流程：

1. 调用 `/api/gettemplatevariable` 获取 `sign1/sign3/timestamp`，用 RC4 算法计算签名（与官方客户端一致）
2. 调用 `GET /api/download?type=dlink&fidlist=[...]` 批量请求下载直链（每批最多 10 个 fid）
3. 根据响应判定：
   - `errno=0` 且全部返回直链 → 整批正常
   - `errno=0` 但部分 fid 的直链被省略 → 被省略的就是"硬和谐"文件
   - `errno=-1` → 组内有"软和谐"文件，自动对半拆分递归定位
4. 定位到单文件后，在"账号健康"前提下连续 2 次一致才落判，防止误报

**两类和谐文件都能识别**：

| 类型 | 特征 | 表现 |
|---|---|---|
| 硬和谐 | download 接口直接省略该 fid 的直链 | 不能下载、不能分享 |
| 软和谐 | download 返回 `errno=-1`，但元数据完全正常 | 缩略图变占位图、分享被拒（errno 109），文件本体有时还能下载 |

> 软和谐最容易被其他工具漏检——它们看元数据一切正常。本工具以"能否获取下载直链"为准，与网盘实际行为一致。

## 使用方法

1. 「检测和谐」页选择账号
2. 设置检测目录（默认 `/` 全盘，建议先扫单个目录验证效果）
3. 按需调整参数：

| 参数 | 说明 | 建议 |
|---|---|---|
| 检测间隔 | 每次 API 请求的间隔毫秒数 | 默认 1000ms；账号热时调 2000~3000 |
| 包含关键词 | 只检测文件名含这些词的文件 | 逗号分隔，留空为不过滤 |
| 排除关键词 | 跳过文件名含这些词的文件 | 逗号分隔 |

4. 选择检测后操作：
   - **仅检测，不操作**（推荐先跑这个看结果）
   - **移动到指定文件夹**：检出的违规文件自动移动
   - **自动删除违规文件**：检出即删除（移入网盘回收站）
5. 点击「开始检测」，页面实时显示进度和违规清单

## 抗限流机制

- 自动识别限流错误码：`-7 / -8 / 112 / 429 / 414 / 31034 / 8001`
- 触发限流 → 指数退避（5s→10s→…→60s），界面显示"已暂停"，**这是在等待恢复，不是卡死**
- 限流等待不消耗重试次数，最多等 20 轮（约 20 分钟）
- 用已判定正常的文件做"参照探针"：区分"接口限流"和"文件真违规"，避免把限流误判成违规

## 结果处理

检测完成后：

- 「违规记录」页查看全部历史检出，支持按账号筛选、导出 CSV
- 「删除违规文件」按钮：勾选部分记录删除，或不勾选直接删该账号全部未删违规文件
- 删除是移入**网盘回收站**，清空回收站前仍可恢复

## 注意事项

- 大目录（数万文件）请分批扫描或留足时间；连续高频扫描会让账号进入限流状态
- 被限流后建议休息 30~60 分钟再继续
- 检测结果保存到本地数据库，重启不丢
