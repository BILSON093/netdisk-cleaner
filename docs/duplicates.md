# 重复文件扫描

按内容找出网盘中的重复文件，智能推荐保留项，一键清理释放空间。

## 判重原理

```
收集目录全部文件 → 按 (文件大小 + MD5) 分组 → 组内 ≥2 个 = 一组重复
```

- MD5 直接取自文件列表接口：小文件是完整 MD5，大文件是百度的"秒传切片 MD5"
- **MD5 + 大小都相同 = 内容相同**（网盘工具通用判据），不同文件名也能查出
- 只调用列表接口（每 100 个文件 1 次请求），**不碰下载接口，不会触发限流**
- 0 字节文件（无 MD5）和文件夹自动排除

## 使用方法

1. 「重复文件」页选择账号，填写扫描目录（默认 `/`）
2. 点击「开始扫描」，进度区实时显示已收集文件数
   - 参考速度：约 1.4 万文件 / 分钟
3. 扫完自动跳到结果页，顶部统计：
   - **重复组**：有多少组内容相同的文件
   - **冗余文件**：可删的文件数（每组总数-1）
   - **可释放空间**：Σ 每组大小 × (数量-1)

## 结果页说明

- 组按**可释放空间降序**排列，大头在前
- 组内按「修改时间升序 + 路径长度升序」排序，**第 1 个为推荐保留**（最早修改的原版），标有「推荐保留」徽章
- 默认勾选除推荐保留外的所有文件，可手动改勾
- **防呆设计**：每组至少保留 1 个，把某组全部勾上会被拦截提示

## 清理

1. 确认勾选无误后，点顶部「🗑️ 删除选中」
2. 确认弹窗后执行，文件移入**网盘回收站**（清空前可恢复）
3. 删除按 50 个一批执行；整批失败时自动逐个重试定位问题文件
4. 已删文件标记「已删除」并置灰，刷新/重启后状态仍在

## 历史扫描

- 每次扫描结果自动保存（每账号保留最近 10 次）
- 「历史扫描」表随时「查看」旧结果继续清理，或「删除」记录（不影响网盘文件）
- 重启工具后可直接从历史恢复，不必重扫

## 适用场景

- 多次转存/备份产生的同名或不同名副本
- 相册、图库批量上传产生的重复
- 释放网盘空间前的冗余审计

## 局限性

- 判重依赖百度返回的 MD5，**极速秒传失败或非常规上传的文件可能 MD5 为空**，此类文件不参与判重
- 仅判"完全相同"，不做相似图片/相似视频识别
