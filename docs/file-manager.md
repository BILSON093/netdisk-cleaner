# 文件浏览与违规记录

## 文件浏览

网页端直接浏览网盘目录：

1. 「文件浏览」页右上角选择账号
2. 点击文件夹进入下级，点击面包屑路径快速返回
3. 文件操作：
   - **检测此目录**：一键跳到「检测和谐」并自动填好当前目录
   - **删除**：移入网盘回收站

## 违规记录

和谐检测的全部历史检出都保存在这里（重启不丢）。

### 筛选与查看

- 左上角下拉框按账号筛选
- 表格显示文件名、完整路径（悬停看全路径）、大小、违规原因、处理状态、检测时间
- 分页浏览，每页 50 条

### 删除违规文件

点顶部「🗑️ 删除违规文件」：

- **勾选了记录** → 只删勾选的文件
- **未勾选** → 删除该账号筛选条件下全部未删除的违规文件（跨页，不止当前页）
- 必须先选择账号（文件按账号归属删除）
- 删除是移入**网盘回收站**，可恢复
- 删除后记录状态自动更新为「已删除」/「删除失败」

### 导出与清空

- **📤 导出**：导出 CSV（UTF-8 BOM，Excel 可直接打开），字段含文件名/路径/大小/原因/状态/检测时间
- **🗑️ 清空**：清空筛选条件下的检测记录（只删本地记录，不动网盘文件）

## 检测任务历史

「检测和谐」页下方展示最近 50 次检测任务：目录、总文件数、已检测、违规数、状态（运行中/完成/已停止）、起止时间。

- 状态为「已停止」的任务可随时重新开始检测同目录
- 任务记录与违规记录关联，便于追溯某个文件是哪次任务检出的
